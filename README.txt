SYLVIA MWIHAKI KIMATHI — PORTFOLIO WEBSITE
Ready to go live. Everything the site needs is in this folder.

WHAT'S INSIDE
  index.html                          the website
  img/                                all project images, posters, wins, portrait
  fonts/                              Kindly Track + Dorky Circle
  js/                                 the two small libraries (handwriting + falling tiles)
  Sylvia_Mwihaki_Portfolio_2026.pdf   the downloadable PDF portfolio
  favicon.png, apple-touch-icon.png   the little matatu icon for browser tabs and phones

HOW TO PUT IT LIVE (pick one)
  1. Netlify (free, easiest)
     Go to app.netlify.com/drop and drag this whole folder onto the page.
     You get a live link straight away; you can add your own domain in Site settings > Domains.

  2. Your own hosting (cPanel, Truehost, Hostinger, etc.)
     Open File Manager, go into public_html, and upload everything in this folder
     (index.html must sit directly inside public_html, next to the img, fonts and js folders).

  3. GitHub Pages
     Make a new repository, upload the contents of this folder, then turn on
     Settings > Pages > Deploy from branch (main, root).

GOOD TO KNOW
  - Keep the folder structure exactly as it is, or images and fonts won't load.
  - The site uses Google Fonts for some text, so visitors need an internet connection (they will have one).
  - To test on your computer, open index.html in Chrome. A few effects (handwriting, falling tiles)
    work best once it's online or served from a local server.
  - Kindly Track and Dorky Circle are fonts you supplied: check their licences allow use on a website.
  - Once you have your domain, tell Claude and it can add a share image so links to the site
    show your picture on WhatsApp, LinkedIn and X.
